# 宅建・資格試験 유튜브 썸네일 스타일 가이드

> **목적**: 지금까지 제작한 「NIPPON リアル」 계열의 탁켄(宅建), 賃管士, 行政書士, 부동산 취업 관련 썸네일 디자인을 다른 이미지 생성 API에서도 일관되게 재현하기 위한 마스터 가이드.
>
> **핵심 인상**: 일본 자격증·시험 정보 채널 특유의 **강렬한 대비 / 큰 일본어 타이포그래피 / 한눈에 들어오는 숫자 / 인포그래픽 요소 / 클릭을 유도하는 의문형 문구**.

---

## 1. 스타일 핵심 규칙

| 항목 | 규칙 |
|---|---|
| 디자인 톤 | 일본 유튜브 교육·시험 정보 채널의 강렬하고 선명한 썸네일. 뉴스 속보 + 자격증 학습 인포그래픽 느낌 |
| 주요 색 | **빨강 · 선명한 노랑 · 진한 파랑 · 흰색 · 검정** |
| 타이포그래피 | 매우 두껍고 크게, 고딕 계열의 일본어 글자. **검정 굵은 외곽선 + 흰색 테두리 + 진한 그림자**. 중요 숫자는 노랑/빨강 |
| 강조 장식 | 사선 배너, 페인트 브러시 스트로크, 체크 표시, 느낌표, 말풍선, 빛 번짐, 빨간 화살표, 동그라미 표시 |
| 배경 | 주제와 관련된 사진·일러스트를 흐리게 배치: 일본 도심 건물, 아파트, 시험지, OMR 답안지, 연필, 법률책, 책상, 달력, 회사 사무실 |
| 정보 밀도 | **메인 문구 하나를 최우선**으로 두고, 작은 보조 문구 2~4개만 사용. 복잡해도 시선을 빼앗지 않도록 |
| 인물 | 필요하면 일본의 20~40대 수험생/직장인 느낌의 사실적인 인물 사진. 표정은 당황·놀람·진지함·자신감 등 영상 주제에 맞춤 |
| 언어 | 이미지 안의 모든 글씨는 **자연스러운 일본어**; 한자, 숫자, 기호 정확히 |
| 시리즈 통일 | 왼쪽 또는 상단에 강한 메인 제목, 오른쪽에 관련 사진/도표, 하단에 보조 정보 띠 |

### 권장 색상 팔레트

- 레드 배너: `#E10600` / 진한 레드: `#B80000`
- 메인 옐로: `#FFEB00` / 하이라이트: `#FFF200`
- 딥 블루: `#082B86` / 선명한 블루: `#0057D9`
- 흰색: `#FFFFFF` / 검정: `#050505`
- 보조 초록: `#159447` (확인/합격) / 오렌지: `#FF8700` (시한·주의)

색상값은 참고용이며 모델이 약간 변형해도 무방합니다.

## 2. 이미지 규격과 화면 배치

### A. 일반 유튜브 영상용 (가로형)

- **비율**: 16:9
- **추천 크기**: `1280 × 720 px` 이상, 가급적 원본 고해상도
- **핵심 구조**:
  1. 상단 좌측 **빨간 배너**: `宅建` / `令和8年度` / `行政書士試験` 같은 주제
  2. 화면 중앙 **대형 노란 메인 헤드라인**: `合格点予想` / `5問免除` / `宅建業法`
  3. 그 아래 **흰색·빨강 보조 문구**: `33〜34点が中心` / `問26〜問45` / `何が変わる？`
  4. 화면 오른쪽 **시험지·체크리스트·달력·빌딩·인물** 중 해당 요소 1~2개
  5. 하단 **파란 정보 띠**: `全20問を解説` / `11/25 9:30` / `未経験の転職戦略`
- **안전 여백**: 글자가 가장자리에 걸리지 않도록 사방 약 5% 확보.

### B. 유튜브 쇼츠용 (세로형)

- **비율**: 9:16
- **추천 크기**: `1080 × 1920 px` 이상
- **핵심 구조**:
  1. 상단 빨강 배너에 `宅建` 또는 `合格点予想`
  2. 상단~중앙 **가장 큰 핵심 숫자/질문**: `1日何時間？`, `時給500円UP？`, `33〜34点？`, `3つだけ？`
  3. 중앙~하단에 작은 정보 카드 1~3개 (평일·휴일 공부시간, 업무 세 가지, 점수별 등)
  4. 하단에 시험지·책·직장인·부동산 이미지
- **쇼츠 주의**: 유튜브 영상 화면의 버튼·설명·계정명이 글자를 가릴 수 있으므로 **우측·아래쪽 가장자리 여백을 넉넉히** 둠. 중요한 텍스트는 중앙부에 모음.
- 쇼츠는 가로형보다 **문구 수를 더 줄이고 숫자와 의문형을 크게**.

## 3. 지금까지 사용한 시리즈별 패턴

### ① 탁켄 시험 과목 해설

**예시 주제**: `都市計画法`, `建築基準法`, `権利関係`, `法令上の制限`, `宅建業法`, `税・その他`.

- 메인: 과목 이름을 **굵은 노란색**으로 강조
- 상단: `宅建士` 또는 `令和8年度`
- 보조: `重要ポイントまとめ`, `解答解説`, `問1〜問14`, `全20問`, `聞き流しで試験対策!`
- 관련 요소: 도시계획 지도, 건축물, 시험지, 체크리스트, 설계도
- 자료 제공 영상만: `PDF OK` 등의 노란 스티커

### ② 합격점 예상·시험 직후 분석

**예시**: `合格点予想`, `11月最新!`, `33〜34点が中心`, `問33`, `11/25 9:30`.

- **숫자 중심**: 큰 점수, 시험일, 합격 발표 날짜를 전면 배치
- 하향 조정/유지 비교는 빨강·파랑으로 시각 구분
- `予想`는 **확정 결과가 아님**을 반드시 표시
- 예상 점수, 기관명, 인원 수는 **사용자가 준 수치만** 사용
- 오른쪽에 답안지/펜/달력/작은 비교표

### ③ 시험 공부법·직전 대비

**예시**: `1日何時間勉強した？`, `300時間`, `2週間で間に合う？`, `前日・当日 最終チェック`.

- 시간을 나타내는 커다란 숫자 + 시계/달력
- 비교형 레이아웃: `重なる範囲 ○` vs `重ならない範囲 ×`
- 공부계획 카드: `平日2h / 休日4h`, `6か月・4か月・3か月`
- 중요 숫자는 제목에서 분리된 큰 노란/빨간 글자

### ④ 자격증 취득 후의 현실·취업

**예시**: `宅建に受かった後の現実`, `宅建合格`, `年収・月給`, `パート・派遣・契約社員`, `大手不動産に入るには？`.

- 자신감 있는 비즈니스 인물 + 일본 오피스 빌딩
- 질문 문구와 직업/급여 숫자를 크게 강조
- 구분 카드: `パート`, `派遣`, `契約社員`, `正社員登用`
- 손익·월급·자격수당·이력서·체크리스트 아이콘
- **기업 로고는 제공된 진짜 원본만 사용**하고, 로고를 임의로 꾸며서 실제 로고인 것처럼 제시하지 않기

## 4. 이미지 생성 API용 공통 마스터 프롬프트 (일본어)

아래 프롬프트에 영상별 정보만 넣어 재사용하세요.

```text
日本の宅建・資格試験・不動産業界を扱うYouTubeチャンネル向けに、
非常に目立つ、プロ品質のサムネイル画像を1枚制作してください。

【動画テーマ】
{テーマ}

【画像サイズ・向き】
{横長16:9 または 縦長9:16}

【画像内に入れる文字：この表記を厳密に守る】
最上部：{上部ラベル}
最重要タイトル：{メインコピー}
強調する数字や問い：{強調コピー}
補足テキスト：{サブコピー1} / {サブコピー2}

【ビジュアルスタイル】
日本の人気資格試験解説YouTubeのような、強烈に視認性が高い
赤・黄色・濃紺・白・黒のインパクトあるデザイン。
重要な文字を極太の日本語ゴシック体で大きく配置。
文字には太い黒フチ、細い白フチ、強いドロップシャドウ。
メインタイトルは画面の最重要要素とし、スマホの小さな画面でも読める。
鮮やかな赤い見出し帯、黄色いブラシストローク、
紺色の情報帯、チェックマークや矢印、光のアクセントを適度に使う。

【背景】
{背景素材：日本の都市、住宅、試験問題、解答用紙、教科書、オフィス等}
関連する写真またはフォトリアルな背景を用い、
文字が目立つよう背景のコントラストを調整する。

【配置】
中心に巨大なメインコピー、右側に関連ビジュアル、
下部に短い補足情報カードまたはバナー。
重要な要素を端で切らない。十分な余白を確保する。

【禁止事項】
誤字、文字化け、架空の数字、指定していない文字、
事実と異なる資格制度の説明、意味のない細かい文字、
無関係なロゴ、透かし、過度な装飾は入れない。
想像で統計・合格点・採用条件を補完しない。
実在企業のロゴは、与えられた正式な素材がある場合のみ使用する。
必ず1枚の完成したサムネイルを出力する。
```

## 5. 세로 쇼츠 전용 프롬프트 (일본어)

```text
YouTube Shorts用の縦長9:16サムネイルを1枚制作。
日本の宅建・資格試験解説チャンネルらしい赤・黄・濃紺の
高コントラストなポップ系サムネイル。

最重要文字：{大きく表示する質問や数字}
上部ラベル：{宅建、賃管士、行政書士など}
補足：{短い説明を1〜2個}

最重要文字を画面の中央に極端に大きく配置し、
太い黒フチと白フチ、強い影を付ける。
周囲に関連する人物イラストまたは写真、時計、試験用紙、
資格証、住宅、チェックリストなどを少数配置。

小さなスマホ画面で一瞬で意味が分かる構図。
細かい情報を詰め込みすぎない。
画面右側や下部に重なるアプリUIを考慮し、重要な文字は中央寄り。
自然な日本語を正確に記し、指定外の数字や断定は追加しない。
```

## 6. 실전 입력 예시

### 예시 A — 합격점 예상 (가로)

```text
テーマ：令和8年度 宅建試験の合格点予想 第3弾
向き：横長16:9
上部ラベル：宅建｜11月最新
メインコピー：合格点予想
強調コピー：33〜34点が中心
サブコピー1：下げた2社・据え置き5社
サブコピー2：11/25 合格発表
背景：宅建の解答用紙、赤で丸をした33、予想推移を示すシンプルなグラフ
※「予想」であり「確定」ではないことを明示
```

### 예시 B — 합격 후 현실 (가로)

```text
テーマ：宅建合格後の登録手順、費用、転職の現実
向き：横長16:9
上部ラベル：宅建合格後
メインコピー：受かった後の現実
強調コピー：約6万円・2〜3か月
サブコピー1：登録の3ステップ
サブコピー2：宅建士だけの3つの仕事
背景：スーツ姿のビジネスパーソン、宅建士証のイメージ、オフィス街
```

### 예시 C — 공부시간 쇼츠 (세로)

```text
テーマ：宅建合格者の1日の勉強時間
向き：縦長9:16
上部ラベル：宅建｜合格者に聞いた!
メインコピー：1日何時間 勉強した？
強調コピー：合計300〜400時間
サブコピー1：平日2時間以上
サブコピー2：休日3時間以上
背景：勉強机、時計、教科書、考え込む受験生
```

## 7. 품질 점검 체크리스트

- [ ] 영상과 **과목·주제·시험 연도**가 정확히 일치하는가?
- [ ] `権利関係`와 `法令上の制限`처럼 과목명을 혼동하지 않았는가?
- [ ] 점수·시험일·합격발표일·금액은 **주어진 자료와 일치**하는가?
- [ ] `予想`, `目安`, `可能性`와 `確定`, `公式`을 혼동하지 않았는가?
- [ ] 일본어 한자와 숫자가 정확하고 작은 화면에서도 읽히는가?
- [ ] 제목은 한눈에 들어오며 보조 문구는 너무 많지 않은가?
- [ ] 가로 썸네일은 **16:9**, 쇼츠는 **9:16** 인가?
- [ ] 중요한 글자가 테두리나 쇼츠 앱 인터페이스에 가려지지 않는가?
- [ ] 필요하지 않은 `PDF OK`나 기업 로고를 임의로 삽입하지 않았는가?
- [ ] 실제 회사 로고가 필요하면 제공된 원본을 그대로 사용하고 있나?

> **핵심 한 줄**: **빨강 헤더 + 초대형 노랑/흰색 일본어 글자 + 검은 외곽선 + 파랑 보조 띠 + 관련 사진/아이콘 + 핵심 숫자 강조**가 지금까지 시리즈의 가장 중요한 공통 스타일입니다.

# 쇼츠 운영 규칙 (2026-11-13 확정)

채널 주인이 확정한 쇼츠 제작 방식. 코드(shorts.py · short_pick.py)와 대본 작성 모두 이 규칙을 따른다.

## 1. 제목
- 형식: `<핵심 숫자가 들어간 한 문장>｜<짧은 질문/반전> <태그2개>`
  - 예: `建設業経理士2級 第39回の合格率は32.0%｜予想どおりだった？ #建設業経理士 #資格`
- 숫자(합격률·합격점·금액·시간)를 **앞쪽**에 둔다. 숫자가 없으면 질문형.
- 태그는 2개만. 宅建 영상은 `#宅建 #宅建士`, 그 외 자격은 spec 의 `short_tags` (예: `#建設業経理士 #資格`, `#賃管士 #賃貸不動産経営管理士`, `#行政書士 #資格`).
- `#shorts` 는 붙이지 않는다.

## 2. 설명란
- **한 줄**(30〜70자). 숫자와 사실만. 예: `第39回（9/13実施）の2級は受験8,511人・合格2,724人で合格率32.0%、合格点は70点。9月回は低めの予想どおりでした。`
- **링크 넣지 않는다.** 본편 유도는 고정 댓글로.

## 3. 고정 댓글
- 본편 URL 이 URL 대장에 있으면: `詳しくは本編で▶ <본편 URL>` (shorts.py 가 .txt 에 같이 출력)

## 4. 썸네일
- **자동 생성하지 않는다.** (autobuild 에서 thumb 단계 제거됨)
- 쇼츠마다 ChatGPT 용 9:16 프롬프트를 .txt 에 같이 출력한다 → 채널 주인이 ChatGPT 에서 직접 만든다.
- 프롬프트 형식은 docs/THUMB_STYLE.md 의 쇼츠 규칙(빨강 띠 · 초대형 숫자 · 黒フチ · 중앙 배치 · 좌우6%/상하8% 여백 · 지정 외 문자 금지).

## 5. 결과·발표 쇼츠
- 공식 발표 숫자가 나오면 바로 쇼츠 전용 스펙(`SHORT_<이름>`, `short_target`=본편)으로 1장짜리를 만든다.
- 「예상 → 결과」 비교를 반드시 넣는다 (예: 予想32〜37% → 結果32.0%).
- 출처(공식 페이지)를 spec notes 에 남긴다.
